# EngineerVerse

Minimal MVP scaffold for a gamified engineering arcade.

## Apps

- `frontend/` - React app UI
- `backend/` - FastAPI app
- `content/challenges/` - challenge definitions
- `docs/` - lightweight project docs

## MVP pages

- Home
- Profile
- Challenge Listing
- Challenge Description
- Drag & Drop Builder
- Simulation
- Score Result
